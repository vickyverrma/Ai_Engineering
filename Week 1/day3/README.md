```python
    )
```

## 📝 Key Points

* A `for` loop can send multiple prompts one after another.
* Each prompt is converted into a message dictionary before making the API request.
* `response.usage` provides information about token consumption.
* `usage.prompt_tokens` shows the number of input tokens.
* `usage.completion_tokens` shows the number of output tokens generated by the model.
* `usage.total_tokens` is the sum of prompt and completion tokens.
* Longer prompts generally require more prompt tokens.
* Longer responses increase the completion token count.
